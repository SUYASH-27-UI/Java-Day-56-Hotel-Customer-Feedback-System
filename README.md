# Java Day 56 – Hotel Customer Feedback Management System

## Description
A menu-driven Hotel Customer Feedback Management System developed using Java. It stores customer reviews, manages ratings and generates an average rating report.

## Features
- Submit customer feedback
- View all feedback records
- Search feedback by customer name
- Calculate average rating
- Filter positive and negative feedback
- Delete feedback using its ID
- Store records permanently in a text file

## Technologies Used
- Java
- OOP
- ArrayList
- File Handling
- Exception Handling

## Files
- `Main.java` – Main Java program
- `feedback.txt` – Sample feedback records

## How to Compile and Run

```bash
javac Main.java
java Main
```

## Concepts Learned
Classes, objects, ArrayList, file handling, searching, deleting records, loops and exception handling.
